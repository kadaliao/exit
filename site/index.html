The true last frame

It starts from exactly what you saw.

Press ⌘W, ⌘Q or ⌘M, or click a close button, and Exit holds the input for a few milliseconds, photographs the window as it is, then lets it go. No stale screenshot, no grey box.

  1. ⌘W
    You close a windowExit notices the shortcut or the click. Every other key passes straight through.
  2. ◉
    Exit takes its pictureThe window, exactly as it looks this instant, held in memory only.
  3. →
    The window closesThe keystroke goes on to the app. If the picture isn’t ready within 160 ms, it goes anyway.
  4. ✦
    The effect playsRight where the window was, starting from that very frame.
More than closing

Every exit, and every entrance.

Closing a window, quitting an app, opening a window and minimizing each get their own effect. Pick one, shuffle, or turn it off.

Effects are just files

One Metal file. Save, and it’s live.

Each effect is a single shader in your Effects folder. Edit it and it recompiles the moment you save. Share it by sending the file.

fade-away.metal✓ Compiled
// @name Fade Away
// @duration 0.35
// @events close, quit, minimize

float4 effect(float2 p, constant Exit& u, texture2d<float> tex) {
    float t = easeInCubic(u.progress);
    float2 c = windowCenter(u);
    float2 q = c + (p - c) / (1.0 - 0.08 * t);
    return sampleWindow(tex, u, q) * (1.0 - t);
}

Effect market

Effects made by other Exit users.

Keeps itself up to date

New versions, installed while you’re away.

Once a day Exit checks GitHub for a new release, downloads it in the background, verifies its signature and Apple notarization, and installs it when you step away from your Mac or quit Exit. Both steps can be switched off.

Stays out of the way

Never steals a click or your focus.

Overlays are click-through and never activate. Exit works across displays, Spaces and full-screen apps, lets you exclude apps or small windows, and goes still when Reduce Motion is on.

Privacy

Your windows stay yours.

Window pictures live in memory for a few seconds. They are never written to disk or sent anywhere.

AccessibilityRequired

To notice windows opening, closing and minimizing, and to briefly hold ⌘W, ⌘Q, ⌘M and close-button clicks for the true last frame. Only those are examined; every other key passes straight through.

Screen RecordingOptional

So the animation starts from the window’s real picture. Without it, Exit animates a card with the app’s icon instead.

When Exit goes online. Only when you generate an effect with AI, once a day to check for a new release, and for the effect market. Those requests download public files; nothing about you is sent. Submitting an effect posts a GitHub issue from your account, and only when you press Submit.
